# What's new in Lithora

Each version's notes also appear on its [release page](https://github.com/Kisaragi000/Lithora/releases)
and in Lithora's update prompt.

## 0.5.6

- Proofread messages now appear in the interface's language (English, Russian or Armenian),
  not in the language of the text they are about.
- Text in table cells is no longer asked to start with a capital letter, so forms stop
  filling up with false grammar marks.
- A fix that puts in one space now says so ("␣ one space"), instead of showing an empty button.
- Update errors (no internet, a failed download) are explained in your language.
- The update prompt lists what's new in the version it offers.
- On narrower windows the History, Settings and Spelling buttons show only their icons, so
  the document's name keeps its room (most noticeable in Armenian).
- The View tab's zoom menu is called "Zoom", so it no longer reads "100%" twice next to the
  100% button.
- The AutoRecover note on the File tab only shows on wide windows, where it fits.
- The side panel's History, Comments and Proofread tabs no longer push the close button out
  of sight: the open tab shows its name, the others their icons.
- Releases carry only the four installers the download table lists (the unused .msi is gone).

## 0.5.5

- A click in the part of a table row carried over to the next page scrolls to that cell's
  text, so you can see where you're typing.

## 0.5.4

- Clicks on the part of a table row carried over to the next page land in the right cell.

## 0.5.3

- Click anywhere in a table cell to type in it, like a spreadsheet.
- Drag cell borders to resize columns and rows; double-click a border to fit the column.
- Click just above a column or left of a row to select it.
- F7 and the Proofread panel scroll to the mistake and flash it.
- File names like ".docx" no longer break in the middle in narrow cells.

## 0.5.2

- The signature window has undo and redo for strokes (Ctrl+Z, Ctrl+Y).

## 0.5.1

- Each tab remembers where you scrolled.
- Vertical alignment button on the Home tab.
- Drag a tab out to open the document in its own window.
- Saving to RTF keeps spacing, fonts, headers and footers much closer to the original.

## 0.5.0

- New View, Design and References tabs.
- Font, Paragraph and Page setup dialogs, a navigation pane and read mode.
- Table of contents, footnotes, captions and cross-references.
- Shapes, equations, watermarks, page color and borders.
- Password-protected files, an English thesaurus, document compare and templates.
- Paste options and print preview.

## 0.4.1

- The font list scrolls itself and is easier to click.

## 0.4.0

- Updates are signed, and Lithora installs only updates signed by its own key.
- Opening a file while Lithora is running adds it to the open window.
- Word, RTF and OpenDocument files can open with Lithora from the file manager.
- Ctrl + mouse wheel zooms; the start-up update check can be turned off in Settings.

## 0.3.5

- Windows: one logo in the title area, with Lithora's own minimize, maximize and close buttons.

## 0.3.4

- AutoSave setting for the recovery copy, Change case (Shift+F3) and slimmer scrollbars.

## 0.3.3

- Proofread panel with grammar and style checks, and Fix all misspellings.

## 0.3.2

- Faster typing: letters appear sooner and the caret glides.

## 0.3.1

- Lithora opens maximized the first time, then the way you last closed it.

## 0.3.0

- Printing, spell check in English, Russian and Armenian, a right-click menu, find and replace,
  Table and Header & Footer tabs, drawn signatures, the History panel, comments, tracked
  changes, crash recovery and Recent files.
